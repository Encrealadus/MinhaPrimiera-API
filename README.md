# API de cursos
API para gerneciamento de **professores** e **cursos**

## Tecnologias
- javascript
- node  js
- mysql
- expess

## endpoits
- `POST /professores` - Cria um professor.
- `GET /professores` - lista professores.
- `POST /cursos` - cria um curso.
- `DELETE /cursos/:id` - deleta um curso por id.
